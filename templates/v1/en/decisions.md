# Session decisions (decisions.md)

> Use this file for what this session **settled**: choices, trade-offs, conventions,
> things you deliberately did not do.
> One `##` heading per decision, with `- decision:` / `- why:` / `- status:` lines.
> Before a model or session swap this goes into the handoff package; unwritten means not handed off.
> Long-lived rules ("in situation X I pick A over B") do not belong here — put them in judgments.md.

## YYYY-MM-DD · Example decision title

- decision: what was chosen
- why: why, and what was given up
- status: active / reverted / watching
